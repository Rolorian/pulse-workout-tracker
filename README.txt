PULSE — WORKOUT TRACKER
Polished offline-first personal workout tracker.

Open index.html in a modern browser. Data is stored in localStorage on that device/browser.

Includes:
- Today dashboard
- Jogging, press-ups, plank, sit-ups, squats, cycling and other exercises
- Reps, minutes, seconds and kilometres
- Back-dated entries
- History
- Streaks and weekly stats
- Personal bests
- Local export
- Delete-all control
- No account/server/database

For iPhone Home Screen PWA installation, serve these files from an HTTPS origin.
